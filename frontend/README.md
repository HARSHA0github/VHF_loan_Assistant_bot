# VHF Bank Loan Assistant - Frontend

This is the proprietary frontend application for the VHF Bank Loan Assistant AI. 
It is built with a high-end Glassmorphism aesthetic and connects to a secure Spring Boot backend for Aadhaar eKYC XML verification and real-time LLM interaction.

## Technologies Used
- React 18
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion (for premium physics-based animations)
- Lucide React (for iconography)

## Getting Started

1. Ensure your Spring Boot backend is running on `localhost:8080`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
